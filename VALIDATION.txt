CHANGES
- The page/zoom/Fit toolbar can minimise, float with a draggable handle, or lock
  to the top or bottom across the PDF working area's width. Locked bars cannot drag.
- Minimise retains a compact current-page summary and a restore control. The
  position menu and reset remain available in compact mode.
- Floating positions stay within the working area on resize. Keyboard arrow keys
  move the handle, with Shift for larger steps; cancelled drags restore the last
  position. In-progress movement is not persisted before pointer release.
- Toolbar mode, normalised floating position and minimisation recover locally.
  Toolbar changes preserve PDF bytes, document scroll and the active PDF tool.
- The document and toolbar share a stage so fullscreen includes both. The stage
  sits between the left navigation and any right tool dock, above page previews.
- Draw now uses its own freehand gesture with a live rounded stroke preview,
  rather than the area-selection rectangle. Every saved point follows that path.
- Native PDF Ink annotations retain pen samples (including coalesced movement and
  release points), with separate gestures stored as separate strokes.
- Only the active primary pointer can extend/end a stroke. Cancellation, lost
  capture, tool changes and page rerenders discard incomplete gestures safely.
- Colour, width, zoom, page origin and drawing page are captured for the gesture;
  later settings cannot alter the stroke being saved. A tap creates a small dot.
- Text appearance settings use a wider, shallow card with a smaller font sample
  and a close button. Closing settings leaves the selected placement tool active.
- Placing a sticky note, text comment, page text, stamp, image, drawing, link,
  form field or visual signature retains the active tool for repeated use.
- Clicking the same feature toggles it off. Choosing another feature replaces it.
  Browsing categories retains it; Done/Escape still exits placement mode.
- Returning to a document restores its own selected tool. Pending placement data
  and original PDF coordinates are retained when the settings popup is dismissed.
- A strict build-time cap keeps the HTML below 25,000,000 bytes (decimal 25 MB).
- Shared PDF/OCR/font/model/source bytes are stored once. Identical source files
  share compressed chunks. Engines, model, font, PDF tools and storage are retained.
- About > Download source bundle reconstructs every source path and file locally.
  Existing compressed chunks are copied directly. Shared assets use native browser
  compression when available, with a valid stored-ZIP fallback when unavailable.
- Source export requires no network or new ZIP decoder. Licences/notices remain.
- A single slim action header, secondary-action menu, soft navy-tinted canvas,
  floating page controls, refined white tool panes and maroon primary actions.
- Home retains open tabs and displays up to six recent PDFs with native first-page
  thumbnails and document-specific Resume actions. Closed copies reopen in one tab;
  existing copies resume without duplication. Library holds the complete list.
- Preview PNGs are bounded, memory-only and invalidated by content revision rather
  than view changes. Invalid saved PDFs have a preview fallback and safe failure.
- Font/colour/size controls are contextual; drawing tools expose actual stroke width.
  Decoration/batch/signature dialogs carry their own appearance controls.
- Secondary actions support keyboard navigation, Escape, outside-pointer dismissal
  and dismissal when focus leaves. Dark theme and reduced motion remain supported.
- IndexedDB retains uploaded PDFs, edits, original bytes, undo/redo, selected images,
  pending redactions, search and document views. Open tabs restore at startup.
- Closed tabs remain available in Local library; explicit Remove deletes a closed copy.
- Critical PDF edits commit before their action completes. View-only updates write
  small view records rather than rewriting PDF binaries.
- PDF/view/catalogue/session changes commit atomically; queued writes preserve newer edits.
- Saved, pending, saving, unavailable and failure states are shown in the footer.
  Quota failures retain in-memory work and the last complete database snapshot.
- Closed copies can be deleted to free storage while quota-limited saves are failing.
- Revision conflicts stop stale app windows from overwriting newer saved workspaces.
- Invalid recovery records are isolated, not silently deleted. Healthy PDFs still open.
- The left navigation has icons with labels and can collapse to a 60-pixel icon bar.
  Collapsed groups retain accessible names and tooltips; the choice is restored.
- Theme, right docking, preview mode and document font are also recovered.
- Local copies can include unlocked source bytes and pre-redaction undo history;
  this retention is explained in Library/About/README. Downloads remain separate.

SCOPE AND RETENTION
Recovery is stored in the browser profile/origin when IndexedDB is available. Quota,
private browsing, browser eviction, clearing site data or changing origin can affect it.
file:// compatibility is browser-dependent and indicated by the app save status.
Local working copies may be unlocked and retain original/undo content after redacted
exports; remove closed copies from Library when appropriate. Download PDFs/workspaces
for backup or transfer. Certificate passwords and signing keys are not persisted.
The application remains an offline PDF toolkit with README.txt limitations; it does
not claim complete Acrobat parity or standards/certificate-trust certification.
